# ✈️ PACK FIT

> **짐은 네가 고르고, 배치는 우리가 한다.**

여행 준비물 목록을 만들고, 캐리어 크기에 맞춰 짐 배치를 **3D로 미리 살펴볼 수 있는** 여행 짐 싸기 웹앱입니다.

## 🎨 디자인 콘셉트

- **화이트 × 스카이블루**: 하늘, 구름, 비행기에서 영감을 받은 밝은 여행 테마
- 태블릿과 모바일 화면에 맞춘 카드형 인터페이스
- 정상 수납 물품과 초과 물품을 구분하는 색상 표시

## 🧳 주요 기능

1. **여행 정보 입력** — 여행지, 출발일·도착일, 캐리어 크기 선택
2. **준비물 추천 및 체크** — 여행 정보에 따른 추천 목록에서 필요한 물품 선택
3. **물품 등록** — 직접 추가하거나 사진 인식 시연 기능을 통해 목록 구성
4. **3D 캐리어 배치** — 물품 크기를 바탕으로 배치 계산, 캐리어 회전 및 개별 물품 확인
5. **짐 넣기·꺼내기** — 단계별 수납 미리보기 및 물품 수량 변경
6. **초과 물품 관리** — 캐리어에 들어가지 못한 물품을 빨간색으로 표시하고 수량 단위로 제외
7. **귀국 모드** — 여행 중 새로 구매한 물품을 추가해 다시 배치

## ▶️ 실행 방법

**실행 파일: [`index.html`](./index.html)**

1. 저장소의 `index.html` 파일을 다운로드합니다.
2. 인터넷이 연결된 브라우저에서 엽니다.
3. 시연용 로그인 화면을 지나 여행 정보와 짐 목록을 입력합니다.
4. **3D 완성본** 메뉴에서 배치 결과를 확인합니다.

> **GitHub Pages**를 설정하면 별도 파일 다운로드 없이 웹 링크로 시연할 수 있습니다. `Settings → Pages`에서 배포 브랜치와 루트(`/`) 폴더를 선택하세요.

## 🛠️ 사용 기술

- HTML / CSS / JavaScript
- React 18, ReactDOM, Babel Standalone
- Tailwind CSS
- Three.js (3D 캐리어 시각화)
- Lucide Icons

현재 앱은 외부 라이브러리를 CDN에서 불러오므로 최초 실행 시 인터넷 연결이 필요합니다.

## 📌 시연 범위 및 유의사항

- 현재 로그인/회원가입 화면은 **시연용**입니다. 실제 서버 인증이 아니므로 실사용 계정이나 비밀번호를 입력하지 마세요.
- 기본 물품 추천은 여행 정보에 기반한 규칙/예시 데이터를 활용합니다. 별도 `/api/recommend` 서버가 없으면 실시간 AI 응답을 보장하지 않습니다.
- 사진 인식은 시연용 예시 이미지 비교 기능을 포함합니다. 사진 한 장으로 실제 물체의 정확한 3D 형상을 복원하는 기능은 아닙니다.
- 3D 물품은 입력된 가로·세로·높이에 따른 상자형 모델이며, 배치 결과는 시뮬레이션입니다. 실제 수납 가능 여부와는 차이가 있을 수 있습니다.
- 회원별 클라우드 데이터 저장/복원 기능은 이 HTML 파일에 연결되어 있지 않습니다.
